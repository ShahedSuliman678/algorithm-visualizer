# Algorithm Visualizer

An interactive web app that visualizes pathfinding and sorting algorithms step by step.

## 🚀 Live Demo
Coming soon...

## 🧠 Algorithms Included
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- More coming soon...

## 🛠️ How to Run
1. Clone the repo
2. Open `index.html` in your browser
That's it — no installation needed!

## 📌 Features
- Draw walls on the grid
- Visualize BFS and DFS in real time
- Control animation speed
- See the shortest path highlighted
